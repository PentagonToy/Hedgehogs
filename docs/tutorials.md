# Examples

Read and copy the notebook code directly on the site. The pages import the original cells and saved outputs without executing them during deployment.

| Example | Includes |
| --- | --- |
| [Plots](tutorials/plots.md) | Lines, scatter, contours, colour bars, panels and export |
| [Tables](tutorials/tables.md) | Formatting, sorting, DataFrames, updates and CSV/LaTeX export |
| [Progress and terminal](tutorials/cli.md) | Iterable/manual progress, messages and redirected output |

Run cells in order after [installation](installation.md). Saved previews can reflect an earlier environment or package version; use the [gallery](gallery.md) for explicitly regenerated examples. Each page also links its original notebook for download and execution.
